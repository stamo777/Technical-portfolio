# Finite Element Analysis – L-Bracket

This project presents a finite element analysis (FEA) of an L-shaped structural bracket using FreeCAD FEM.

The study investigates the influence of geometry and mesh refinement on the predicted stress distribution 
and deformation of the component.

## Objectives

- Design and analyse an L-bracket using finite element analysis
- Evaluate stress concentrations under mechanical loading
- Compare different mesh resolutions
- Investigate the influence of a geometric reinforcement (stiffener)
- Assess the convergence and reliability of the numerical results

## Tools

- FreeCAD FEM
- CalculiX
- Finite Element Method (FEA)

## Report

The complete methodology, simulation setup, results and discussion are available in the PDF report included in this repository.
